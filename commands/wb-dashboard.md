allowed-tools: Bash(uv run:*), Bash(uv --version), Bash(ls:*)

Пересобери дашборд wb-review-insights. Аргумент: `$ARGUMENTS` — имя списка
(имя файла со ссылками без расширения). Субагентов не запускай и отзывы
не анализируй — только скрипт. Пиши пользователю по-русски и коротко.

1. Если папки `wb-insights` нет — скажи, что запусков ещё не было, и предложи
   `/wb-review-insights:analyze-competitors <файл со ссылками>`. Остановись.
2. Если `$ARGUMENTS` пустой — выполни `ls wb-insights`, покажи имена папок
   (кроме файлов) как доступные списки и попроси выбрать. Если список один —
   используй его без вопроса.
3. Выполни:

   ```bash
   uv run "${CLAUDE_PLUGIN_ROOT}/scripts/dashboard.py" "wb-insights/<имя списка>"
   ```

4. Ответь:
   - путь к `dashboard.html` (открывается в браузере двойным кликом) и строку
     со сводкой из вывода скрипта;
   - если скрипт сообщил об ошибке в `wb-insights/dashboard.toml` — покажи её
     и подскажи, какую строку поправить;
   - если в выводе есть предупреждения о неизвестных блоках или разделах —
     перескажи их.
